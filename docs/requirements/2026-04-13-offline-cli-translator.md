# 离线命令行中英互译需求文档

- 日期：2026-04-13
- 状态：冻结，待用户复核

## 1. 目标

在当前目录创建一个适用于 `WSL Arch` 的离线命令行翻译工具，支持中文转英文、英文转中文，默认以交互模式运行，并允许首次联网下载模型、后续完全离线使用。

## 2. 交付物

- 一个基于 `Python` 的命令行程序，命令名暂定为 `trans`
- 一个交互式 `REPL`
- 一个单次翻译入口
- 模型安装或初始化说明
- 最小验证用例与运行说明

## 3. 已冻结的产品决策

### 3.1 技术方案

- 运行时：`Python`
- 离线翻译引擎：`Argos Translate`
- 工作模式：首次联网下载 `zh -> en` 与 `en -> zh` 模型，下载完成后本地运行

### 3.2 命令体验

- `trans`：进入交互模式
- `trans "你好"`：执行一次性翻译
- `trans -f zh -t en`：以指定方向进入交互模式

### 3.3 交互命令

- `:q`：退出
- `:swap`：在 `zh -> en` 与 `en -> zh` 间切换
- `:from zh`：临时指定源语言
- `:to en`：临时指定目标语言
- `:auto`：回到自动识别

### 3.4 自动识别边界

- 自动识别仅覆盖中文与英文两种语言
- 若输入包含明显中文字符，则按 `zh -> en`
- 否则按 `en -> zh`
- 混合语言句子不做复杂语言检测

## 4. 成功标准

- 能翻译完整句子，不是只做逐词查词
- 在无网络时，只要模型已安装，仍可完成中英互译
- 默认交互模式可连续输入多句并逐条返回结果
- 单次翻译与交互模式都可正常使用
- 模型缺失时能给出明确提示，而不是静默失败

## 5. 约束

- 优先追求安装和使用简单，而不是最高翻译精度
- 精度目标为“日常句子够用”
- 不引入重型本地大模型方案
- 不扩展到中英以外语言

## 6. 非目标

- 不实现多语种自动检测
- 不实现复杂术语库、上下文记忆或批量文件翻译
- 不实现守护进程、服务端模式或 TUI 界面

## 7. 验收标准

- 输入中文句子时，默认返回英文
- 输入英文句子时，默认返回中文
- 使用 `-f`、`-t` 时，应覆盖自动识别逻辑
- `:q`、`:swap`、`:from`、`:to`、`:auto` 均可在交互模式中生效
- 缺失模型时，程序应输出可执行的安装提示

## 8. 手工抽查

- `trans`
- 在交互模式输入一条中文句子与一条英文句子
- 在交互模式执行 `:swap`
- `trans "你好"`
- `trans -f zh -t en`

## 9. 已知取舍

- 该方案以轻量和可维护性为优先，翻译质量会低于在线服务和更大型本地模型
- 自动识别规则保持简单，避免为少量边缘输入引入额外依赖
